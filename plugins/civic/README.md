# 🏛️ Civic

Граждански умения за [Claude](https://claude.ai): по-лесни сигнали до институциите в България.
*Civic skills for Claude: easier reports to Bulgarian authorities.*

| Умение · Skill | Какво прави · What it does |
|---|---|
| [🚗📸 Подай глобата](skills/podai-globata/README.md) · [EN](skills/podai-globata/README.en.md) | Снимки на неправилно паркирана кола → готов официален сигнал до правилната институция. *Photos of a wrongly parked car → a formal report to the right authority.* |

👉 **Търсите „Подай глобата“? [Инсталиране и употреба](skills/podai-globata/README.md)** · кратък линк: [zdravkov.dev/podai-globata](https://zdravkov.dev/podai-globata)

Инсталиране на всички граждански умения в Claude Code · *Install all civic skills in Claude Code*:

```
/plugin marketplace add ivan-zdravkov/ivan-the-terminal
/plugin install civic@ivan-the-terminal
```
